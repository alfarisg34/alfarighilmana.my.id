# Design System: Obsidian Cyber-Canvas & Matrix Compute

A visual computing and interactive terminal identity created for **Alfari Sidnan Ghilmana** (`alfarighilmana.my.id`). This world highlights Alfari's core technical strengths: 60 FPS Canvas RPG trees, Web GIS interactive maps, algorithmic budget parsers, and automated AI compute pipelines.

## 1. Palette & Surface Materials

- **Obsidian Dark Void (`--bg-main: #05080e`)**: Deep space matrix surface.
- **Compute Terminal Panel (`--bg-surface: #09101d`)**: Elevated workstation cards with hairline phosphor borders.
- **Phosphor Green (`--primary-emerald: #10b981` / `#00ff88`)**: Primary telemetry signal, system status online, and active compute nodes.
- **Cyber Cyan (`--primary-cyan: #06b6d4`)**: High-speed network flow and interactive links.
- **Solarized Amber (`--primary-amber: #f59e0b`)**: Enterprise security credentials, warnings, and hardware flags.

## 2. Typography System

- **Display & Headings**: `Chakra Petch` (Google Fonts, 600/700 weight) — A precision cybernetic face with clean chamfered glyphs and distinct personality.
- **Body & Prose**: `Outfit` (400/500/600 weight) — Highly legible geometric structure with optical balance.
- **Terminal & Specs**: `JetBrains Mono` (500/600/700 weight) — Code blocks, architecture ASCII maps, and hardware specs.

## 3. Visual Craft & Interactive Leverage

- **Interactive Canvas Network**: Ambient particle compute constellation rendered at 60 FPS on vanilla HTML5 Canvas that subtly reacts to cursor proximity.
- **Terminal Viewports**: Project architecture maps rendered in dark CRT workstation windows with live terminal dots.
- **Precision Chamfer Radii**: Crisp 3px-6px borders on interactive chips and buttons, avoiding generic pill blobs.
